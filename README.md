  # OOP Exam 02 - Examination System

  Console application in C# that simulates an examination system.

  - Question base class with TrueFalseQuestion and MCQQuestion
  - Answer class (AnswerId, AnswerText)
  - Exam base class with FinalExam and PracticalExam
  - Subject class that creates its exam
  - Implements ICloneable and IComparable, overrides ToString, uses constructor chaining

  ## Run

  dotnet run
